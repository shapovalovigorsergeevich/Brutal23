# THE GENTLEMEN — 3D landing page

Откройте `index.html` в браузере.

Особенности:
- тёмная luxury-стилистика;
- CSS 3D barber chair + золотой световой ринг;
- parallax от мыши;
- автосмена 5 hero-слайдов и управление стрелками;
- адаптив под мобильные;
- интерактивная форма записи;
- без сборщика и локальных зависимостей.

Для продакшена можно подключить реальный booking API и добавить фотографии/3D-модели.
